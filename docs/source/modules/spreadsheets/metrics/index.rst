Metrics
=======

`Ipea <https://www.ipea.gov.br/portal/coluna-3/institucional-sep/quem-somos>`_ is a public institution responsible for research that supports and guides public policy development.  
The data generated from these studies is centralized in a public platform called `Ipeadata <https://www.ipeadata.gov.br/Default.aspx>`_.

The platform provides three main categories of data:

- *macroeconomic*: Economic and financial data for Brazil, available in yearly, monthly, and daily time series, using standardized monetary units.
- *regional*: Economic, demographic, and geographic data for states, cities, administrative regions, and catchement areas.
- *social*: Data and indicators related to income distribution, poverty, education, health, and social services, including breakdowns by gender, ethnicity, and other demographics.

For this project, only *macroeconomic* metrics are used.
