.. _classes:

Classes
=======

The *Classes* module provides a simplified way to handle common logic shared across different parts of the system.

- :ref:`CVM <cvm_classes>`: (Comissão de Valores Mobiliários) responsible for handling date adjustments and generating CVM links
- :ref:`IPEA <ipea_classes>`: (Instituto de Pesquisa Econômica Aplicada) responsible for generating IpeaData links
- :ref:`Pandas <pandas_classes>`: responsible for standardizing the use of ``DataFrame`` and ``Series`` across the project
